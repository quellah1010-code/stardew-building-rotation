## 坐标合同

每格 16 **源像素**，不是游戏世界或屏幕像素。占地左上角为 `GroundOrigin`，布局坐标乘 16 再加原点。门槛取门区外向边中点，不是角色位置或已验证的传送落点；世界中建筑的位置不进入局部画稿坐标。

当前策略将正面主体底边与占地底边对齐，上部余量为 `主体高度 − 正面占地高 × 16`；侧向保留同样余量。这是重画用的画布策略，不是推导出了真实侧面投影。后续需要扩画布／增加屋檐时，明确调整地面原点，保持门的地面锚点不漂移。

| 建筑 | 正／背面草稿画布 | 左／右侧草稿画布 | 地面原点 |
| --- | --- | --- | --- |
| Barn | 112×112 | 64×160 | (0,48) |
| Shed | 112×128 | 48×192 | (0,80) |
| Stable | 64×96 | 32×128 | (0,64) |

Barn 图集整体 112×128，主体只取 112×112；Y=112 以下是动物门素材区，不算主体高度。四个动物门首帧的裁切、位置及开门偏移独立保留。Shed 的零 `SourceRect` 按默认全纹理解析为 112×128。[源字段说明](https://stardewvalleywiki.com/Modding:Buildings)

三种建筑的 `DrawOffset` 均为零。自动模板拒绝非零偏移或不符合约定的裁切，避免猜测游戏偏移单位。`SortTileOffset` 仅保留原值，未模拟游戏层级；马厩值为 1，接入时不能漏掉。

## 分层职责

| 图层 | 作用与 Reveal 关系 |
| --- | --- |
| `ground-guide` | 木板／石子视觉引导，不放置地面物品，不跟屋顶淡化，不改通行 |
| `shadow` | 独立校准投影，不整张随屋顶透明 |
| `base-outline` | 保留墙脚及可辨认的碰撞边界，透明度待实机 |
| `upper-occluder` | 屋顶／上墙，仅背面靠近真实门时分层淡化 |
| `human-door-and-sign` | 真实门与门框标识，清晰并对齐当前门区 |
| `animal-door-moving-parts` | 与门状态同步；侧／背面不能直接套正面开门偏移 |

这些不是最终绘制顺序或深度值。Reveal 距离、透明度、过渡、闪烁抑制尚未定参数。正面动物门图层与背面 Reveal 图层不是同一概念。

`ArtTemplate` 读取已经覆盖后的朝向门，测试验证了重构北门时锚点跟随。提交底稿使用基准门位的几何变换；正式门位一旦重构，要重生成指导，不可只改画而保留旧触发点。
