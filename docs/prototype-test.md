# 空牛棚旋转实验版 0.1.7

本版仅按 0.1.6 实机反馈调整两侧配图：门朝屏幕左边（West）使用无木箱的整墙，门朝右边（East）使用带附属木构的图。白边、88×107 的侧图尺寸、绘制原点与正背面均保持原样；用户已反馈 0.1.6 的尺寸看起来合适。四个 DLL 沿用 0.1.6，输入、碰撞、进出门与存档代码未改。

## 安装与操作

完全退出游戏，将 ZIP 内的 `BuildingRotation.Prototype` 替换 `Mods` 中旧的同名文件夹。若仍留有 `BuildingRotation.Diagnostics`，移除该旧版本文件夹，避免同一个 UniqueID 加载两次。保留 Let's Move It、现有“旋转测试”存档及其中的普通空牛棚。

通过 SMAPI 启动，`br_status` 应显示版本 **0.1.7**，以及 `white-trim Barn art 3/3 loaded; South uses game art`。缺图时日志会列出具体朝向，并回退为格子占位；请检查 `assets` 子文件夹是否一同复制。

当前环境为游戏 1.6.15、SMAPI 4.5.2、Let's Move It 0.6.20；仅单人普通 Barn，未升级／施工、没有动物，除默认固定取草槽外没有玩家物品或家具。已有取草槽无需拆除。

操作保持原样：默认 Alt＋左键拿起后松开 Alt；右键按住约 0.35 秒并横拖至少约 24 屏幕像素，旋转一档；右键松开仍保留预览，左键点击放下，Esc 取消。一次按住最多转一档；单选、关闭复制和多选，原搬动键保持单独的左键。原 LeftControl 是搬动 mod 的强制键，不是旋转键。

## 这轮只看两侧对应

| 真实入口方向 | 游戏应显示的侧图 |
| --- | --- |
| 门朝左／West，青框在左 | 无箱子的完整红墙和白色收边 |
| 门朝右／East，青框在右 | 近端带附属木构，屋顶、白边与图高不变 |

旧四视图板中 LEFT／EAST、RIGHT／WEST 的配对属于此前审图记录，本包以这张表和实际门朝向为准。此次按用户指定的画面对应换图，不改朝向枚举、旋转几何或保存数据。

用已有测试牛棚转到这两侧各看一眼即可，前轮通过的旋转、非法位置拒绝、Esc 恢复、绕行、进出门和基本存读档不用整套重测。0.1.6 截图中的 p2／p4 都是青框在左且带木构的同一面，不能算两种不同侧向均已拍到；本次换图尚待实机确认。

青色空心框仍标记真实门外格。当前代码每次绘制时画框，没有根据玩家距离显隐的逻辑；用户观察到靠近时出现框，暂不据此断定显隐原因，也不将它当作 Reveal 完成。北侧框在屋顶上方，人物仍可能被整张屋顶遮住，分层与 Reveal 待后续实现。

本版保持整张 sprite、原生 4 倍及墙脚对齐。侧图高 107 像素，侧向占地纵深 112 源像素，上沿相差 5 源像素；保留已获尺寸正常反馈的比例。青框与移动红绿框来自真实布局，不以贴图透明像素改碰撞。

## 本包验证与边界

这是素材修正包，没有改 C# 运行逻辑，不重新编译或重复核心自检／Harmony 审计。四个 DLL 与 0.1.6 逐字节一致；0.1.6 的 Smapi DLL 是用匹配游戏／SMAPI 引用直接 Roslyn 编译的产物。运行时版本提示读取 manifest，因此 `br_status` 显示 0.1.7，DLL 内部编译版本仍沿用此前版本。

两侧安装素材按上述对应互换，均与原选稿字节一致，北向素材不变；它们的 native 尺寸为 88×107、88×107、113×107。地面原点按 `(图宽 - 占地宽×16)/2, 图高 - 占地高×16` 计算，两侧为 `(12,-5)`，北向为 `(0.5,43)`；负 Y 表示图上沿位于占地顶线以下。源像素以 4 倍绘制，不改变已保存的建筑位置／尺寸／门区。

这版不支持动物、升级、联机、其他建筑、Reveal、旋转动物门动画或外观 mod 适配。测试期间保持该牛棚为空。后续增加分层及门口显露，再检查人物遮挡效果。普通空牛棚的完整多实例、出口受阻、异常中断等验证仍保留原待办；当前基本流程实测通过不代表这些全部通过。

开发环境正常时仍可运行：

```sh
dotnet build src/BuildingRotation.Smapi/BuildingRotation.Smapi.csproj -c Release -p:GamePath="/path/to/game"
python scripts/package-diagnostics.py
```

打包器也支持 `--build-dir /path/to/verified/build`，核对源 manifest 和三张素材后按明确清单打包。ZIP 仅含四个自有 DLL、manifest、本说明和三张自有 PNG，共九个文件；游戏／SMAPI／Harmony／Let's Move It 的 DLL、原版贴图、个人存档、截图和反编译源码不发布。
