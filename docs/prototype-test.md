# 空牛棚旋转实验版 0.1.9

修正 0.1.8 实机反馈：北侧看起来应能横穿的位置仍被实心格挡住，门像独立梯子，双重透明让墙脚一起消失。本包实际改变了北向碰撞与门位，不是仅换图。普通空 Barn、单人范围不变；本版尚待游戏内确认。

## 安装和这轮检查

完全退出游戏，把 ZIP 内 `BuildingRotation.Prototype` 替换 `Mods` 中的同名文件夹。已有 Let's Move It 和测试档保留，不需新建牛棚。`br_status` 应显示 **0.1.9**、`white-trim Barn art 3/3 loaded`、`North Reveal layers ready`。不要同时留相同 UniqueID 的旧版文件夹。

只检查本次改变的北面：从原先被挡住的那条路线左右横走一次，随后走到新门前右键进入、出门一次。门和阻挡墙线向建筑内收一格，出门应回到这排通路。继续朝墙走仍应被阻挡。靠近时屋顶变淡，木门连着红墙，墙脚应保持可见；退开恢复整栋。最后退出重进，确认这条路和新门位仍一致。无需重测东西两侧配图、旋转手势或整套取消流程。

原操作：Alt＋左键拿起后松 Alt；右键按约 0.35 秒并横拖至少 24 屏幕像素转一档，松右键保留预览，左键放下，Esc 取消。LeftControl 仍是搬动 mod 的强制键。单选、无复制／多选、原搬动键只绑定左键。

## 实际边界怎样改

| 北向布局 | 0.1.8 | 0.1.9 |
| --- | --- | --- |
| 放置预留范围 | 7×4 | 7×4，保留完整检查，不能与旁物重叠 |
| 最北一排 | 实心阻挡 | 可通行，宽 7 格、深 1 格 |
| 实心区域 | 四排 | 后三排；南端／左右边缘原位 |
| 人门局部格 | (5,0) | (5,1) |
| 人物站位／返回格 | (5,-1) | (5,0)，在可通行首排内 |
| 动物门区域 | (2,0,2,1) | (2,1,2,1)，仅保持定义一致，仍不支持动物 |

这是为已选北面美术设置的明确布局覆盖，不是原版 Barn 数据有可走首排，也不是矩形旋转算法计算错了。原始数据保留；普通同尺寸、实心、标准门位 Barn 才应用此校准。内容 mod 的特殊碰撞或门位不覆盖。其他三个方向、图片大小、白边及建筑保存坐标保持原样。

新布局同时用于矩形碰撞、按格通行、预览、门交互、返回落点及加载重建。原朝向存档值不变；旧 North 实例读入时自动用新门位重建出口。室内仍不转向。

## 显示修正

北向绘制不再乘游戏 `Building.alpha` 的整栋淡化值，由分层 Reveal 单独控制：屋顶最低 22%、墙面 38%、底部六行保留原透明度。旧版 16%×40% 导致屋顶实际最低约 6.4%，基座也只剩 40%。不更改游戏建筑的 alpha 字段。

显露覆盖整条北侧通路及其后方屋顶遮挡区，而非只在门附近生效。从左侧接近也会开始显露；约 0.18 秒淡入、0.25 秒恢复，退出区域扩 0.5 格防抖。新门有实体木门板，外部板条不会再透过门框形成梯子横档；红墙、门槛、地面边界对齐到同一条实心墙线。引导仍是图层，不生成物件。

点击木门仍要求玩家在门前一格、面朝南，执行原 `Building.doAction`。靠近显露不扩大传送范围。新北门槛在原 North 图片坐标 `(88.5,59)`；原图地面锚点 `(0.5,43)`、113×107 尺寸不变。[离线对照](art/runtime/barn-north-reveal-runtime-v2.png)只是素材和坐标检查，不是实机画面。

## 验证与限制

匹配游戏 1.6.15.24356、SMAPI 4.5.2、Let's Move It 0.6.20 引用的 Roslyn 编译通过。Core／Smapi 重新编译；Runtime／Data 沿用 0.1.8，旧构造函数二进制签名保留。因为修改了公共碰撞查询，运行完整自检 **131/131 通过**（新增 13 项北向校准检查，含游戏实际 48×32 步行碰撞框横穿、贴边与穿墙、门／返回、旧朝向值加载、其他方向与实例隔离、移动取消）。原始数据转换检查也通过；未重做未改的 Harmony 目标签名审计。

直接编译沿用已验证 SDK／引用，不把它写成标准 MSBuild 构建。本环境之前的 MSBuild 进程信息错误未另行重试。离线检查不能代替真实游戏中的走路、遮挡排序、缩放点击、加载验收；还不能说碰撞体验或门外观已获用户通过。

范围仍是单人普通空 Barn，无施工／升级／动物、玩家物件／家具；默认固定取草槽保留。动物、其他建筑、联机、室内转向、马厩显露仍未实现。完整多实例存档与异常中断验证保留待办。
