# 空牛棚旋转实验版 0.1.10

把用户本轮要求一起交付：撤掉显露时横着的红墙，改成地面石地板；最底下的墙脚一起淡化；北向牛棚按整栋四周两格触发透明，包括右侧、南侧和四个角，不再只认门或北侧通路。

## 安装和本次检查

完全退出游戏，把 ZIP 内 `BuildingRotation.Prototype` 替换 `Mods` 中同名文件夹。已有 Let's Move It 和测试档继续用。`br_status` 应显示 **0.1.10**、`white-trim Barn art 3/3 loaded` 和 `North Reveal layers ready`。

在现有北向牛棚右侧、前侧各靠近一次：进入外扩两格范围即开始淡化；上下墙体和底边一起变淡，下面显示灰色石地板。退到范围外恢复。无需重新放置建筑或重测整套旋转流程。若要确认边缘，以人物脚底中心到建筑地面占地框的距离为准，不以鼠标位置判断。

原控制不变：Alt＋左键拿起，松 Alt；右键按约 0.35 秒并横拖至少 24 屏幕像素转一档，松右键保留预览，左键放下，Esc 取消。LeftControl 仍为 Let's Move It 强制键。单选、无复制／多选、原搬动键只绑定左键。

## 本次显示与触发规则

- 以完整 7×4 预留占地为基准，左右、上下各外扩 **2 格**，四个角同样有效。玩家面朝哪边不影响显露。
- 已触发后退出界限再放宽 0.5 格防止边缘闪烁；约 0.18 秒淡入、0.25 秒恢复。进入圈内无需等待点击。
- 屋顶最低不透明度 22%；上墙、底部六行都最低 38%，共用相同过渡，不再有一截完全不透明的红边。
- 删除运行时红色远墙绘制。新增自制 32×32 石地板图集，按实际阻挡格铺在地面层，门前一格也用较淡石面作入口引导；人物和门仍在其上层。未放大、竖立成墙或新增场景物件。
- 石地板仅显露时出现，地面层不等于允许走进实体建筑。北侧第一排通路仍可走，门前格仍是 `(5,0)`。
- 北向忽略游戏的整栋 alpha，避免与分层透明重复相乘。其他朝向仍沿用此前显示方案；本批扩大的是北向建筑四周的接近范围。
- 显露范围与传送范围分开：右键木门仍要求真实门前一格和面朝南，任意一侧靠近显露不会直接传送。

## 沿用 0.1.9 的布局

标准普通 Barn 的 North 仍保留 7×4 放置范围；最北首排可行，后三排阻挡。人门 `(5,1)`、站位和返回 `(5,0)`，动物门定义 `(2,1,2,1)`；动物行为仍未开放。实际通行、门、返回、朝向存储均未更改。其他方向的布局、白边和已认可的大小不变。

只支持 Stardew Valley 1.6.15.24356、SMAPI 4.5.2、Let's Move It 0.6.20 下的单人普通空 Barn。无施工／升级／动物、玩家物件／家具；默认固定取草槽不拆。其他建筑、联机、室内转向和马厩显露仍未实现。

## 验证

匹配引用直接 Roslyn 编译通过，Smapi DLL 重新编译；Core／Runtime／Data 与 0.1.9 完全相同。**29/29 针对性检查通过**：四边与四角触发、两格精确边界、退出防抖、平滑淡化、移动／重置／实例隔离、门点击仍受原站位限制，以及原北侧通路检查。修正自检 `--reveal-only` 参数曾被 Content 输入解析误拒的问题；未重跑其余未改逻辑。上版全量 131/131 是历史结果，不当作本版新增数量。

石地板／图层／打包检查通过；这不等于游戏中的新效果已获用户确认。包共 14 文件：四个自有 DLL、manifest、说明、八张自有 PNG。无用户截图、存档、游戏或第三方程序集。
