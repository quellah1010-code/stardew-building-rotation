# 空牛棚旋转实验版 0.1.8

本版纠正 0.1.7 的 East／West 配图，并首次接入北面入口的分层 Reveal。保留已认可的白边、图高与比例；仍仅支持单人普通空 Barn。这里的 Reveal 是可试装的初版，尚未获得实机反馈，不代表所有美术／遮挡已验收。

## 安装与操作

完全退出游戏，将 ZIP 内 `BuildingRotation.Prototype` 替换 `Mods` 里的同名文件夹。已有 Let's Move It 和测试档保留；不要同时留另一个相同 UniqueID 的 Diagnostics／Prototype 副本。`br_status` 应报告版本 **0.1.8**、`white-trim Barn art 3/3 loaded` 和 `North Reveal layers ready`。少图时日志会说明，Reveal 不完整时保留正常北面图。

环境仍为 Stardew Valley 1.6.15、SMAPI 4.5.2、Let's Move It 0.6.20。普通 Barn 不升级／施工、没有动物，除默认固定取草槽外没有玩家物品或家具。取草槽无需拆除。

默认 Alt＋左键拿起后松开 Alt；右键按住约 0.35 秒并横拖至少约 24 屏幕像素转一档，松开右键保持预览，左键放下，Esc 取消。单选、关闭复制和多选，原搬动键单独绑定左键；LeftControl 仍是搬动 mod 的强制键。

## 两侧现在怎样对应

| 入口朝向 | 从固定镜头看见的面 | 附属木构 |
| --- | --- | --- |
| East：入口朝屏幕右边 | 建筑左侧墙 | 在远侧，不画近端木箱，显示完整红墙 |
| West：入口朝屏幕左边 | 建筑右侧墙 | 位于近侧，显示木构 |

左右视图名称不等于门朝屏幕哪边。原版正面的附件在右边，按既有坐标变换，朝 East 时它转到远侧，朝 West 时转到近侧。0.1.7 直接对调贴图的处理已撤回；朝向枚举、已保存方向、碰撞、门位未更改。正面继续使用游戏原图。

## 这轮看北门 Reveal

把现有测试牛棚放成 North，退出搬动模式。从建筑北侧门口附近走近：屋顶和上墙逐渐变淡，墙脚保留，真实北门处出现白边门框及门外引导。青框随 Reveal 淡出；远离后恢复原图与青框。两侧和正面不触发 Reveal，拿起时显示普通完整预览。

进入仍需站在真实门外一格、面朝建筑；现在也能右键点显露出来的门框，调用原门交互。靠近范围大于可进入范围，但不会扩大传送范围。进门再出来后，靠近显露应重新生效。

只需看左右配图一次，再做一次“北门远→近→退开”和一次门框点击。重点反馈：人物是否看得清、墙脚是否留下、边缘是否闪、门框能否正常进入。之前通过的放置、取消、绕行及基本存读档不重测整套。

## 初版参数与验证边界

按人物碰撞框底边中心判断与真实北门的相对位置。触发区从门向外 3 格，左右各扩 1.5 格，内侧容许 0.25 格；退出区额外扩 0.5 格，防止边界抖动。约 0.18 秒显露、0.25 秒恢复，屋顶保留 16% 不透明度、上墙 30%、底部 6 源像素保持原样。参数是本次默认值，未经过实机调优。

三张 113×107 分层图合起来逐个可见像素还原原 North 图，未改其色彩与形状。独立 16×28 门框的 `(8,26)` 锚定真实门槛；北门普通牛棚局部格为 `(5,0)`、门外格 `(5,-1)`。门框、门外木板及占地轮廓只负责显示，不创建物件、碰撞或存档字段。屋顶透明可能同时露出地上原有物体，当前是建筑剖视提示，不是完整室内重建。

本环境标准 dotnet 启动仍遇到进程信息错误，已用同一 SDK 的 Roslyn 和匹配引用直接编译通过（Release 优化、nullable、警告视为错误，排除 SDK 默认的 1701／1702）。新显露状态／点击边界共 **14/14 项独立检查通过**；未重复原有 104 项或未改的 13 个 Harmony 目标审计。核心、数据、运行层 DLL 沿用 0.1.7，SMAPI DLL 重新编译。

这不等于 SMAPI 中实际过渡、人物排序、不同缩放下的点击已经通过。现阶段仍不支持动物、升级、联机、其他建筑、马厩侧面显露、室内旋转或外观 mod 适配。更完整的多实例保存、出口受阻及异常中断验证保留原待办。

开发环境正常时：

```sh
python scripts/build-barn-north-reveal.py
dotnet build src/BuildingRotation.Smapi/BuildingRotation.Smapi.csproj -c Release -p:GamePath="/path/to/game"
dotnet run --project tests/BuildingRotation.Core.SelfTest -- --reveal-only
python scripts/package-diagnostics.py
```

打包器可用 `--build-dir /path/to/verified/build` 指定已验证产物。包内四个自有 DLL、manifest、本说明和七张自有 PNG，共 13 个文件；不分发游戏／SMAPI／第三方 DLL、原版贴图、用户截图或存档。
