# 空牛棚旋转实验版 0.1.6

本版装入白边版 East／West／North 三张图；正面放下后交回游戏原绘制，预览从游戏贴图及门图层取材。新图保持原生比例，墙脚与占地下沿对齐，不再拉长屋顶。拿起及放下共用绘制原点；输入、碰撞、进出门与存档代码未改。

## 安装与操作

完全退出游戏，将 ZIP 内的 `BuildingRotation.Prototype` 替换 `Mods` 中旧的同名文件夹。若仍留有 `BuildingRotation.Diagnostics`，移除该旧版本文件夹，避免同一个 UniqueID 加载两次。保留 Let's Move It、现有“旋转测试”存档及其中的普通空牛棚。

通过 SMAPI 启动，`br_status` 应显示版本 **0.1.6**，以及 `white-trim Barn art 3/3 loaded; South uses game art`。缺图时日志会列出具体朝向，并回退为格子占位；请检查 `assets` 子文件夹是否一同复制。

当前环境为游戏 1.6.15、SMAPI 4.5.2、Let's Move It 0.6.20；仅单人普通 Barn，未升级／施工、没有动物，除默认固定取草槽外没有玩家物品或家具。已有取草槽无需拆除。

操作保持原样：默认 Alt＋左键拿起后松开 Alt；右键按住约 0.35 秒并横拖至少约 24 屏幕像素，旋转一档；右键松开仍保留预览，左键点击放下，Esc 取消。一次按住最多转一档；单选、关闭复制和多选，原搬动键保持单独的左键。原 LeftControl 是搬动 mod 的强制键，不是旋转键。

## 这轮只看新图

转一圈看四个方向，拿起／放下后是否保持同一位置与比例。正面应恢复原版；另外三面应显示白边新图，不再是金棕色格子。侧墙不额外画门，青色空心框仍标记真实门外格。进入方式、返回位置和室内摆放保持原样。

拍图时带上人物及旁边原版建筑，方便判断大小。重点看墙脚是否像浮起或埋进地里、两侧宽度是否舒服、人物靠近入口时是否被挡得难以操作。北侧青框会画在屋顶上方，表示屋顶后面的真实门外格；本版尚无 Reveal，人物在背面仍可能被屋顶遮住，这不是完整背面可见性验收。

本版只用整张 sprite 绘制，未分层。侧面原图高 107 像素，侧向占地纵深 112 源像素，两者不能同时以等高图片覆盖所有地面格；本版选择保持图高／比例并对齐底边，上沿差 5 源像素。青框与移动时的红绿框来自实际布局，不以贴图透明像素改碰撞。这项是否观感合适，需要本次实际画面判断。

前轮已通过的旋转、非法位置拒绝、Esc 恢复、绕行、进出门和基本存读档不用整套重测。若新图出现位置偏移、残影或错误日志，反馈对应截图／错误段即可。`active=False` 在没拿起建筑时、`Save loaded: False` 在尚未载入存档时均正常。

## 本包验证与边界

0.1.6 已用匹配游戏／SMAPI 引用直接调用 SDK 8.0.424 的 Roslyn 编译器编译，Release 优化、nullable、警告视为错误；使用 SDK 默认的程序集统一警告排除 1701／1702。本环境的常规 dotnet／MSBuild 启动在读取进程信息时失败，因此不声称本轮标准工程构建成功。Core／Runtime／Data 未修改，沿用已有 Release 产物；未重复 104 项独立检查或 13 个补丁目标签名审计。

三张安装素材与选稿字节一致；它们的 native 尺寸为 88×107、88×107、113×107。地面原点按 `(图宽 - 占地宽×16)/2, 图高 - 占地高×16` 计算，两侧为 `(12,-5)`，北向为 `(0.5,43)`；负 Y 表示图上沿位于占地顶线以下。源像素以 4 倍绘制，不改变已保存的建筑位置／尺寸／门区。

这版不支持动物、升级、联机、其他建筑、Reveal、旋转动物门动画或外观 mod 适配。测试期间保持该牛棚为空。后续增加分层及门口显露，再检查人物遮挡效果。普通空牛棚的完整多实例、出口受阻、异常中断等验证仍保留原待办；当前基本流程实测通过不代表这些全部通过。

开发环境正常时仍可运行：

```sh
dotnet build src/BuildingRotation.Smapi/BuildingRotation.Smapi.csproj -c Release -p:GamePath="/path/to/game"
python scripts/package-diagnostics.py
```

打包器也支持 `--build-dir /path/to/verified/build`，核对源 manifest 和三张素材后按明确清单打包。ZIP 仅含四个自有 DLL、manifest、本说明和三张自有 PNG，共九个文件；游戏／SMAPI／Harmony／Let's Move It 的 DLL、原版贴图、个人存档、截图和反编译源码不发布。
