# 保存重进：测试副本准备

2026-09-15：用户上传两份存档，已根据日期、金币和建筑布局确定与实机画面相符的来源，制作单独交付的 `BuildingRotation-TestSave.zip`。私人存档、识别资料及 ZIP 不进入公开仓库；本页只记录做法和下一步。

## 如何与原档分开

核对用户提供的游戏 1.6.15 程序：`SaveGame` 加载时从槽名第一个下划线之前读取保存名前缀，写入时使用 `FilterFileName(Game1.GetSaveGameName()) + "_" + Game1.uniqueIDForThisGame`。前缀采用不含下划线的字母串，另设游戏编号，目录和主文件同名，正常保存路径仍指向测试槽。

副本只改 5 个 XML 文本字段：主文件的 `uniqueIDForThisGame`、`player/name`、`player/farmName`，以及 `SaveGameInfo` 的 `name`、`farmName`。选档界面显示“旋转测试”及带测试标记的角色名。游戏编号也参与随机结果，副本不承诺与原档后续随机结果相同；人物所有权编号保持原样。

包内只有新槽的当前主文件、对应 `SaveGameInfo` 和安装说明，不混入来源的 `_old` 备份。没有写入旋转 modData 或预造牛棚；这两步仍由实际游戏完成。

## 已核对与待验证

已核对 XML 可重读，主文件与选档资料一致；反向撤回上述 5 处字段后，整份 XML 的规范化结果与来源完全一致。两份输入 ZIP 的校验和未变，输出 ZIP 的目录、CRC 和文件字节已检查。安装包 0.1.2 未改动，不重复构建或核心自检。
